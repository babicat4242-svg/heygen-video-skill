# 공식 출처와 확인 순서

확인일: 2026-11-02. 기능과 API는 변경될 수 있으므로 실제 실행 시 현재 문서를 우선한다.

- [HeyGen 개발자 문서](https://developers.heygen.com/): API·CLI·MCP, 인증, 현재 스키마를 찾는 진입점. API 개발 요청이나 연동 설정 시 확인한다.
- [Video Agent 시작하기](https://www.heygen.com/academy/video-agent/make-your-first-video-with-video-agent): 브리프 입력, 발표자·음성 선택, 영상 옵션과 계획 검토의 공식 안내. 웹 작업 시 현재 UI와 대조한다.
- [Video Agent 아카데미](https://www.heygen.com/academy/video-agent): 프롬프트 작성, 계획 검토, 수정, 다운로드를 작업에 맞게 찾아본다.
- [영상 번역 시작하기](https://help.heygen.com/en/articles/10029081-how-to-get-started-with-video-translation): 번역 작업의 지원 범위와 원본 준비를 확인한다.
- [HeyGen 공식 스킬 저장소](https://github.com/heygen-com/skills): 공식 에이전트 워크플로를 추가 참고할 때 사용한다. 이 개인 스킬은 공식 배포본을 복제한 것이 아니다. 외부 스킬의 설치 명령·자격증명 처리·작업 권한을 자동 채택하지 않는다.

필요한 문서만 읽고, 실제 도구 스키마 또는 CLI 도움말과 대조한다. 서로 다르면 현재 사용 중인 연동의 지원 범위를 확인하고 확인된 방식만 실행한다.
